# Инженер-конструктор (Расчетчик несущих строительных конструкций)

## Роль и задачи в современности
Инженер-конструктор применяет генеративный дизайн и методы машинного обучения для автоматического поиска идеальной формы узлов, расчета зданий на экстремальные нагрузки (землетрясения, ураганы) и минимизации расхода металла и бетона.

---

## Рекомендуемые ИИ-инструменты
* **Autodesk Generative Design** — генеративный ИИ, создающий сотни вариантов оптимальной формы деталей или каркасов на основе заданных нагрузок и веса.
* **SCAD Office / LIRA-SAPR (с модулями автоматизации)** — софт для расчета прочности, использующий алгоритмы оптимизации сечений.
* **ChatGPT / GitHub Copilot** — для написания макросов и скриптов на C# / Python для автоматической выгрузки усилий из расчетных комплексов в чертежи.

---

## В чем конкретно помогает ИИ
* **Генеративный дизайн деталей:** ИИ предлагает причудливые, но максимально прочные формы для металлических узлов, опор и ферм, которые весят на 20-40% меньше стандартных, экономя миллионы на закупках стали.
* **Предиктивный расчет на прочность:** мгновенно симулирует поведение конструкции при землетрясениях разной балльности, выявляя слабые места (концентраторы напряжений) в фундаменте или стыках.
* **Подбор сечений:** автоматически просматривает тысячи комбинаций толщины стен и диаметров арматуры, выбирая самый дешевый вариант, полностью проходящий по критериям безопасности (первой и второй группе предельных состояний).

## Промты для работы

### Промт для проверки граничных условий расчета
> `Я рассчитываю пространственную металлическую ферму пролетом 36 метров для складского комплекса в Московском регионе. Напомни мне нормативные значения снеговой и ветровой нагрузки по СП 20.13330, а также коэффициенты надежности по нагрузке, которые я должен заложить в расчетную схему.`

### Промт для написания макроса оптимизации
> `Напиши код на Python, который берет массив данных (значения изгибающих моментов в двутавровых балках) из CSV-файла, находит максимальное значение и по таблице сортамента (ГОСТ) автоматически подбирает минимально необходимый номер двутавра, удовлетворяющий условию прочности по моменту сопротивления Wx.`
