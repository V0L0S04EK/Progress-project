# Специалист по проектированию «Умных домов» и систем автоматизации (IoT)

## Роль и задачи в современности
Специалист по автоматизации внедряет ИИ непосредственно в инженерную экосистему здания, связывая датчики, мультимедиа, безопасность и климат в единую самообучающуюся сеть.

---

## Рекомендуемые ИИ-инструменты
* **Home Assistant с интеграцией локальных LLM (ИИ)** — для создания голосового управления и предиктивных (предсказывающих) сценариев внутри дома без отправки данных в облако.
* **Iridium Pro / KNX инструменты автоматизации** — платформы для диспетчеризации крупных жилых комплексов и коммерческих зданий (BMS).
* **ChatGPT / GitHub Copilot** — для написания кода автоматизации (YAML, JavaScript, C++) для контроллеров и интеграции сторонних устройств по протоколам Modbus/MQTT.

---

## В чем конкретно помогает ИИ
* **Предиктивный климат-контроль:** ИИ изучает привычки жильцов, прогноз погоды за окном, теплоемкость стен и заранее плавно регулирует теплые полы и кондиционеры для идеального комфорта к их приходу.
* **Предотвращение аварий:** анализирует микровибрации в трубах или скачки тока в приборах, обнаруживая скрытые протечки воды или износ бытовой техники до того, как случится поломка.
* **Умная безопасность:** отличает домашних животных от реальных нарушителей на камерах видеонаблюдения и может имитировать присутствие хозяев дома (включать свет, музыку), если зафиксирует подозрительную активность у забора.

## Промты для работы

### Промт для написания сценария автоматизации (YAML для Home Assistant)
> `Напиши код автоматизации YAML для Home Assistant. Условие: Если датчик движения в прихожей фиксирует движение в период с 23:00 до 06:00, то включить светодиодную ленту в коридоре на 10% яркости. Через 2 минуты отсутствия движения плавно выключить свет.`

### Промт для разработки концепции системы для заказчика
> `Составь понятное для обычного клиента описание системы автоматизации (Умный дом) для загородного коттеджа площадью 200 кв.м. Объясни простыми словами, без сложных технических терминов, какие выгоды в плане безопасности, экономии на отоплении и ежедневного удобства он получит от интеграции управления светом, шторами и климатом.`
