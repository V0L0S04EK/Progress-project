# Специалист по работе с клиентами / Риелтор новостроек

В эпоху цифровой трансформации продажи в недвижимости переходят от стандартных буклетов к интерактивному клиентскому опыту. Искусственный интеллект становится главным инструментом для персонализации предложений, позволяя визуализировать будущее жилье под конкретные запросы покупателя и автоматизировать рутинные этапы ведения сделки.

::: info Роль и задачи в современности
Специалист отдела продаж девелопера использует ИИ для создания индивидуальных презентаций квартир, моментальной генерации 3D-туров из обычных планировок и автоматизации первичного общения с клиентами через умных чат-ботов.
:::

## Рекомендуемые ИИ-инструменты

Для автоматизации взаимодействия с покупателями и создания эффектного визуального контента сформировался следующий ИИ-стек:

* **Planner 5D / Homestyler** — планировщики интерьеров с ИИ, которые создают фотореалистичный дизайн-проект квартиры по одной фотографии чертежа за 5 минут.
* **Midjourney / Magnific AI** — нейросети для апскейла и улучшения качества рендеров, проработки видов из окон ЖК и детальной визуализации коммерческих помещений.
* **ManyChat / Chatfuel с интеграцией OpenAI** — умные диалоговые роботы для круглосуточной квалификации лидов, ответов на вопросы о стоимости квадратного метра и записи на просмотр 24/7.

---

## В чем конкретно помогает ИИ

Интеграция искусственного интеллекта в работу коммерческого блока позволяет повысить конверсию в сделку и сократить цикл продаж:

1. **Мгновенная визуализация для клиента**
   Помогает покупателю «голой» квартиры в бетоне сразу увидеть на экране планшета 3-4 варианта готовой отделки и расстановки мебели именно под его стиль жизни.
2. **Автоматический консалтинг**
   ИИ-бот на сайте мгновенно отвечает на сложные вопросы клиентов о доступных банках по семейной ипотеке, условиях эскроу-счетов и проектной декларации.
3. **Персонализация предложений**
   Автоматически анализирует анкету клиента и формирует PDF-презентацию с акцентом на важные для него вещи (для семейных — детские сады рядом, для инвесторов — доходность).

## Практические промты для работы

Вы можете использовать эти проверенные шаблоны запросов для автоматизации инженерных задач и работы с документацией.

### 1. Промт для генерации рекламного описания планировки
> `«Действуй как элитный брокер по недвижимости. Напиши продающий, эмоциональный, но без лишней "воды" текст для описания евро-трехкомнатной квартиры (72 кв.м) с мастер-спальней, гардеробной и панорамными окнами на реку в ЖК бизнес-класса "Ривер Парк". Целевая аудитория: молодая семья с ребенком. Выдели преимущества планировки для их повседневного комфорта».`

### 2. Промт для отработки возражения по цене
> `«Клиент пишет: "Ваш жилой комплекс слишком дорогой, в 15 минутах езды от вас есть ЖК от другого застройщика, где квадратный метр стоит на 20% дешевле". Напиши вежливый, убедительный ответ менеджера по продажам. Сделай упор на закрытый двор без машин, собственную школу во дворе, использование премиального кирпича вместо панелей и более высокую ликвидность объекта в будущем».`
